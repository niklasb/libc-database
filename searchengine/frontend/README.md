This frontend uses Vite with React 19.

## Available Scripts

In the project directory, you can run:

### `npm run dev`

Starts the Vite development server.

### `npm start`

Alias for `npm run dev`.

### `npm run build`

Builds the app for production into `dist`.

### `npm run preview`

Starts a local server for the production build in `dist`.
